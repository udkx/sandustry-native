# Изменения

## 0.1.0 — 22.08.2026

Первая сборка, пригодная для тестирования на чужих машинах.

### Что работает

- **Ядро физики на Rust**, перенесённое построчно из игры: вертикальный шаг с
  трассировкой, баллистический шаг сыпучего, шаг жидкости и газа, раздача
  горизонтальной скорости при ударе, обмен по плотности, ветка упакованного
  элемента.
- **Установщик** (`installer/`): находит игру в библиотеке Steam на трёх
  платформах, сохраняет `app.asar`, патчит `main.js` и воркер симуляции, кладёт
  ядро рядом с ресурсами. Откат возвращает сохранённую копию байт в байт.
- **Моды и ядро разведены**: `nodeIntegrationInWorker` включается только когда
  моды Workshop выключены, иначе мод получил бы доступ к файловой системе через
  Node. Запуск с модами — `--with-mods`.
- **A/B-замер на живой игре**: `SANDUSTRY_NATIVE_AB=N` переключает ядро фазами,
  все воркеры синхронизируются по общим часам без обмена сообщениями.

### Исправлено по дороге

- **Карта реакций оставалась грубой навсегда.** Модуль смесей игры появляется
  только после первого вызова из физики — позже, чем ядро успевает его
  спросить. До этого действовала пометка «участник любой смеси реагирует со
  всем подряд», и вода с песком, которые есть почти в каждом чанке, отправляли
  в JS 57 % всех обойденных клеток: 4.9 млн вызовов `matterPhysics.cJ` за
  интервал, 56 % времени тика. Игра с ядром была **медленнее оригинала на
  26 %**. Теперь мост переспрашивает карту, когда модуль появился, и снимает
  грубые пометки. Подробности — §17 в `docs/game-contracts.md`.
- Растр перерисовывается настоящим `cellOps.Gz` по списку изменённых клеток:
  без этого мир считался верно, а на экране выглядел рваным пятнами по границам
  чанков.
- Путь лога берётся у системы, а не зашит как `/tmp`: на Windows такого пути
  нет.

### Чего пока нет

- Чанк с машиной рядом целиком уходит старому коду — 28 % неспящих чанков и
  73 % оставшегося времени. Следующая работа: гейт по клетке вместо гейта по
  чанку.
- Не воспроизведён `margin` обхода, которым игра чередует границы между
  потоками; поведение на стыках полос отличается от оригинала.
- Только Sandustry 0.5.2 из Steam.
